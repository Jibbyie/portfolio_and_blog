About the Project

Rizztaurant is a visual novel set in a chaotic yet empty restaurant where you must charm your way through a bizarre encounter and reel in an absurd chef. Built in Ren'Py and Python, it's a stylistic blend of comedy, narrative design, and expressive character art, all created by me except for the soundtrack. The project explores timing, tone, and interactive dialogue as tools for both humour and connection.

Technical Highlights

  • Branching dialogue structure with persistent choice tracking
  • Custom UI styling and animated character expressions
  • Scene transitions, sound mixing, and timed dialogue reveals
  • Script modularity across narrative chapters using Python logic

Development Focus

  • Writing expressive, comedic dialogue with mechanical consequences
  • Designing character-driven narrative arcs and pacing
  • Creating all visual assets including sprite art and backgrounds
  • Establishing a modular codebase for future expansion

What I’ve Learned So Far

  • Managing visual storytelling with Ren'Py's scripting engine
  • Balancing humour with character consistency and branching logic
  • Integrating original artwork into scripted gameplay flow
  • Organising narrative complexity across multiple act files
