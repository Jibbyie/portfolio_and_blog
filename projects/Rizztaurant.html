My contribution

Programming the rhythm of an interactive story.

I built the Ren'Py and Python systems that connect dialogue, player choices, scene transitions, character presentation, UI, sound, and timed comedic beats. The visual and narrative work supports the programming problem: making branching interactions feel coherent and responsive.

Technical highlights

Persistent narrative state.

  • Tracked branching choices so earlier decisions could affect later dialogue and scene flow.
  • Used Python logic to keep narrative chapters modular rather than placing the entire story in one script.
  • Implemented custom UI styling, animated character expressions, scene transitions, and timed dialogue reveals.
  • Integrated sound and presentation cues so timing carried the intended comedic rhythm.

Development challenges

Challenge → approach → result

  • Branching complexity: Persistent choice tracking kept consequences readable while allowing scenes to be authored independently.
  • Timing: Dialogue reveals, transitions, character animation, and sound were coordinated as one presentation sequence rather than isolated effects.
  • Iteration: Modular chapter scripts made it easier to revise narrative beats without destabilising the rest of the project.

Development decisions

Keep story logic separate from presentation.

The project uses Python logic and modular Ren'Py scripts to separate persistent state and scene flow from individual presentation beats. That trade-off keeps the narrative easier to expand while preserving control over tone and timing.
